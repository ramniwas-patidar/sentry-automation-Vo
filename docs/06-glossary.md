# 06 — Glossary

Plain-English definitions for every jargon term used in this project. Skim this before reading the source.

---

### API (Application Programming Interface)
A documented contract that lets one program talk to another over the network. In practice: a set of URLs you can call with HTTP requests to read or change data on a remote system.

### API token / API key
A long secret string that authenticates your program to a remote API. Acts like a password tied to a service account. See [05-external-services §0](./05-external-services.md).

### `async def` / `await`
Python syntax for *coroutines* — functions that can pause while waiting on slow I/O without blocking the whole program. Only used here in the FastAPI webhook handler.

### Background thread
A separate worker that runs concurrently with the main program. Used so the webhook can return a response immediately while the slow pipeline runs in parallel.

### Behavioral test
A test that simulates a real user flow (clicks, renders) rather than checking a specific function. In this project, generated by GPT and run with Jest + React Testing Library.

### Branch (git)
A named pointer to a line of commits. Pipelines create a new branch like `fix/sentry-3issues-20260506-130801`, commit fixes there, and open a PR from it.

### Commit (git)
A snapshot of the repository at a moment in time, with a message describing the change.

### Cooldown / debounce
The 30-second delay that prevents the same project from triggering the pipeline twice in quick succession. Implemented with the `_last_webhook_trigger` dictionary in `server/__init__.py`.

### Coroutine
See `async def`.

### Daemon thread
A thread that gets killed automatically when the main program exits. Used so a still-running pipeline doesn't keep the server alive after `Ctrl+C`.

### Decorator
A Python function that wraps another function. Written as `@something` above a `def`. FastAPI uses decorators (`@app.post(...)`) to map URLs to handlers.

### Deterministic test
A trivial test that just checks "does the file contain this exact string after the patch?". Used as a sanity check that the file edit applied at all.

### `.env` file
A plain text file holding `KEY=value` pairs of secrets and config. Loaded by `python-dotenv` in `config.py`. Never committed.

### FastAPI
The Python web framework used to define HTTP endpoints. `@app.post("/url")` turns a Python function into a URL handler.

### Fingerprint (Sentry)
Sentry's grouping key for errors — different stacktraces can share a fingerprint and be merged into one issue.

### HMAC signature
A cryptographic checksum of a webhook body, computed with a shared secret. Lets us verify the webhook actually came from Sentry. See `SENTRY_CLIENT_SECRET`.

### HTTP / HTTPS
The protocol web browsers and APIs speak. HTTPS = HTTP with TLS encryption. All four external services (Sentry/OpenAI/GitHub/Jira) are accessed over HTTPS.

### Idempotent
Safe to call multiple times with the same input. The webhook handler tries to be idempotent via debouncing.

### Issue (Sentry)
A single grouped error in Sentry. Contains a title, stacktrace, event count, and metadata.

### Issue (Jira)
A ticket in Jira. We create one per fixed Sentry issue. Has a key like `CSPI-2014`.

### Jest
A JavaScript test runner. The `test_command` typically invokes `npm test`, which runs Jest under the hood.

### LLM (Large Language Model)
A neural network that takes text in and produces text out. We use OpenAI's `gpt-4o-mini` by default to read errors and produce code fixes.

### Lock (`threading.Lock`)
A synchronization primitive: only one thread can hold the lock at a time. Used to prevent two pipelines from clobbering the same git repo.

### Middleware (FastAPI)
A function that intercepts every HTTP request before/after the endpoint runs. We use one — `ScannerBlockMiddleware` — to drop vulnerability scanner traffic.

### Module / Package
**Module** = a `.py` file. **Package** = a folder of modules with an `__init__.py` inside. Both are imported the same way.

### `npm test`
A shell command that runs the test script defined in a JavaScript project's `package.json`. Configured per-project as `test_command`.

### OpenAI SDK
The official Python client library for OpenAI's API. Imported in `llm/claude.py` (despite the file name).

### Patch / `file_edit`
A find-and-replace pair (`original` → `replacement`) that the LLM produces to fix a bug. Multiple patches can be returned for one issue.

### Pipeline
The 7-step process: fetch → filter → branch → fix → test → PR → Jira. Defined in `server/__init__.py` (`_execute_pipeline`).

### Port
A number identifying a specific listener on a machine. This server listens on port `8000`. Two programs can't bind the same port.

### PR (Pull Request)
A proposal on GitHub to merge a branch into another branch. Each pipeline run produces one PR with all the fixes batched together.

### Process
A running program with its own memory. The whole server runs in one Python process.

### Pydantic
A Python library for declaring data shapes as classes. FastAPI uses it to validate request/response bodies automatically. See `models/schemas.py`.

### PyGithub
A Python wrapper around the GitHub REST API. Used in `pipeline/pr_creator.py` to open PRs.

### Repo (repository)
A git project. Identified here by `github_repo` in the project config (e.g. `primathontech/wellversed`).

### REST API
An HTTP API that uses standard verbs (GET/POST/PUT/DELETE) on URL paths to manipulate resources. All four external systems expose REST APIs.

### Rotating log file
A log file that auto-truncates: when it hits 10 MB, the file is renamed to `.1`, a new file starts, and old `.5` files are deleted. Configured via `RotatingFileHandler` in `server/__init__.py`.

### Sentry
An error monitoring SaaS. See [05-external-services §1](./05-external-services.md#1-sentry--servicessentry_servicepy).

### Service (in this codebase)
A class that wraps one external system's API (`SentryService`, `GitHubService`, etc.). Hides HTTP/auth details from the rest of the code.

### Singleton
An object that exists exactly once per process. `services/llm_service.py` returns a singleton LLM client so we don't recreate the OpenAI client on every call.

### Slug
A URL-friendly identifier. Sentry projects have slugs like `wellversed-prod`.

### Stacktrace
The list of function calls that led to an error, with file paths and line numbers. The LLM uses this to find which file to edit.

### Subprocess
A child process spawned by Python. Used to run `git` and `npm test` commands.

### TDD (Test-Driven Development)
The practice of writing a failing test *first*, then writing the code that makes it pass. The "TDD fix loop" mimics this: test fails before the fix, passes after.

### Thread
A unit of execution within a process. Multiple threads share memory but run independently. The webhook spawns a background thread so the HTTP response can return immediately.

### Token
See API token.

### Type hint
Optional Python annotation describing what type a variable/argument should be. Not enforced at runtime, only by editors and type checkers.

### Uvicorn
The ASGI web server that actually listens on TCP port 8000 and runs the FastAPI `app`. Started by `main.py`.

### Verified (in this project)
A fix is "verified" only if the LLM-generated behavioral test FAILS before the patch and PASSES after. Otherwise the fix is `unverified` (still applied, lower confidence).

### Virtual environment
An isolated folder of Python libraries (`.venv/`) so this project's dependencies don't conflict with other projects on your machine.

### Webhook
An HTTP request *one* server sends to *another* server when an event happens. Sentry sends us webhooks when new errors occur. Opposite of polling.

### Webhook signature
See HMAC signature.

---

That's the full vocabulary. Anything missing? Open a PR adding it here.
